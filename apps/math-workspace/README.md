# Math Workspace（智能数学工作台）

首个原生鸿蒙应用的产品与工程入口。

## 产品目标

把平板变成可交互的数学工作空间，而不是简单的电子笔记本：数学表达式、推导步骤、图形和解释之间应能建立结构化关联。

## 首期范围（拟定）

1. 工作区与文档列表。
2. 可滚动、可缩放的数学画布。
3. 公式块与文本块的基础编辑模型。
4. 推导步骤的组织与引用。
5. 本地保存、恢复与基础导出。

## 非首期范围

- 自动证明或保证数学推导正确；
- 全功能手写公式识别；
- 在线多人协作；
- 自动同步全部设备数据；
- 未经评估的后台常驻或高权限能力。
