# AlgoLab build scripts

Windows DevEco Studio is the primary workflow; see the [local development guide](../docs/development-guide.md). The Linux scripts and self-hosted runner below are optional and have not yet been validated with the API 26 SDK.

## Optional Linux prerequisites

Run on a machine or CI runner with Huawei **Command Line Tools 26.0.0 Release** configured. The DevEco Studio graphical IDE is not required.

After configuring the matching Command Line Tools and Node.js, install the DevEco CLI:

```bash
npm install -g @deveco/deveco-cli@latest
devecocli help
```

See the [official DevEco CLI command reference](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-deveco-cli-options/) and the [CLI package](https://www.npmjs.com/package/@deveco/deveco-cli).

## Generate the Stage project

From the repository root:

```bash
bash scripts/bootstrap-algolab-stage.sh
```

The script:

1. Calls Huawei's `devecocli create` with API level 26 and bundle ID `com.haibao.algolab`.
2. Verifies that the generated Stage template contains its application and module metadata.
3. Overlays the tracked AlgoLab domain model, C++ generator and ArkUI page.
4. Copies the result to `dist/AlgoLab-Stage`.

It deliberately does not write `build-profile.json5`, `module.json5`, Hvigor files, signing profiles or certificates by hand. Those are generated by the matching official toolchain.

Optional environment variables:
- `ALGOLAB_APP_NAME` (default: `AlgoLab`)
- `ALGOLAB_BUNDLE_NAME` (default: `com.haibao.algolab`)
- `HARMONYOS_API_LEVEL` (pinned to `26`; other values are rejected)

Optional first argument: output directory. The directory must not already exist.

## Build the generated project

```bash
cd dist/AlgoLab-Stage
devecocli build --modules entry --build-mode debug
```

Huawei documents this command as the CLI route for building a module HAP. The matching Command Line Tools package includes the SDK, Hvigor, ohpm, Node.js and HDC.

## Cloud CI constraints

The repository does not yet contain a CI workflow that downloads Huawei's proprietary Command Line Tools. Huawei directs developers to obtain the package from its Download Center and verify its integrity. The Linux pipeline guide specifies 64-bit Linux, GLIBC 2.28+, at least 8 GB RAM, and 100 GB disk (16 GB RAM recommended).

A GitHub-hosted standard runner must not be assumed to satisfy those requirements. Before enabling automatic HAP builds, provision a runner with the documented resources and a legally obtained, checksum-verified Command Line Tools package. Never commit signing certificates, private keys, or passwords.


## Lightweight GitHub Actions check

`.github/workflows/algolab-bootstrap-check.yml` runs on relevant pull requests and main-branch changes. It checks Bash syntax and verifies that the three ArkTS overlay inputs exist. This is a lightweight repository check only; it does **not** install the HarmonyOS SDK, compile ArkTS, or produce a HAP.


## Optional: build a HAP through GitHub Actions

The repository includes a manual-only workflow at `.github/workflows/algolab-harmonyos-hap.yml`. It targets a self-hosted Linux runner with the `harmonyos-api-26` label, validates memory/disk/GLIBC and the installed SDK paths, installs DevEco CLI, generates the Stage project and builds the entry HAP.

See [cloud runner setup](../docs/cloud-build-runner.md). The workflow cannot run until a qualifying runner is registered and online.
