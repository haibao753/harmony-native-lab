

## 2026-11-08 — 0.4.3 Live Deformation Heatmap & Lite Rendering

### 用户反馈

- 0.4.2 的实体模型已可见，但运行仍比较卡。
- 形变热力模式没有可见内容。

### 处理

- 将 AR 网格发布最小间隔从 100 ms 调整为 200 ms，目标约 5 Hz，降低 JS / Canvas 连续绘制压力；ARView 自身渲染仍由 AR Engine 驱动。
- 热力图改为双基准策略：有中性表情基准时显示当前网格相对中性网格的逐顶点位移；没有中性基准时显示相邻帧逐顶点动态位移。
- 在热力图图例中标记 `NEUTRAL Δ` 或 `LIVE MOTION Δ`，避免用户误以为两种热力含义相同。
- 将“采集基准”快捷操作移至观察器标题栏。

### 验收边界

以上是代码级修正，不代表真机性能或热力图已经通过验收。若 5 Hz 下仍明显卡顿，应采集设备上的 DRAW CALL / JS 耗时，并转向 ArkGraphics3D GPU 原生网格方案评估。
