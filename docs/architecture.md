# 架构约定

## 基本原则

- **原生优先**：ArkTS + ArkUI + Stage 模型。
- **按 API 能力设计**：所有系统 API 以项目实际 SDK 文档与编译器提示为准。
- **模块边界清楚**：页面、领域逻辑、数据访问和平台能力分层。
- **本地优先**：核心编辑流程不应依赖网络；同步与 AI 能力作为可选服务。
- **可验证**：不把未经构建的伪代码描述为可运行实现。

## 建议分层

```text
UI（ArkUI 页面、组件、主题）
        ↓
Application（页面状态、用例、协调逻辑）
        ↓
Domain（数据结构模型、规则、分析）
        ↓
Data（本地存储、导入导出、远程数据源）
        ↓
Platform adapters（HarmonyOS 系统 Kit）
```

这是一种逻辑分层建议。实际目录结构应以 DevEco Studio 生成的工程模板为基础，再逐步演进。

## 首个应用：AlgoLab

AlgoLab 首期聚焦单链表实验：
- 画布中的节点创建、移动与指针连接；
- 逻辑引用与画布坐标分离；
- head 可达性、环和不可达节点分析；
- 教学内存视图；
- 从结构模型确定性生成 C++ 代码；
- 本地保存与恢复。

华为笔记负责笔记和 PDF 标注，系统浏览器负责网页阅读，HarmonyOS 系统负责多窗口。AlgoLab 不重复实现这些系统或成熟应用已有的通用能力。

- `apps/algolab` 包含 DevEco Studio 官方模板生成的 Stage 工程配置。
- 已在 DevEco Studio 26.0.0.865 / HarmonyOS SDK 26.0.0.105 构建未签名 debug HAP；尚未完成签名、安装和 MatePad Pro 13.2 真机验证。

- 连接操作当前采用选择起点、再选择目标的交互；直接拖拽连接端口仍待真机验证。
