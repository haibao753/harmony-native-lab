**Platform target:** HarmonyOS API 26 / Stage / ArkTS / ArkUI

## Goal

Establish a reliable input foundation for MatePad Pro 13.2 with Huawei M-Pencil and finger touch. M-Pencil is used for ink expression; finger touch remains responsible for direct graph manipulation and multi-touch canvas navigation.

## Included

### 1. Input source routing
- Uses ArkUI `TouchEvent.sourceTool` to classify `SourceTool.Pen`, `SourceTool.Finger`, and other input sources.
- Node drag gesture updates only for finger input.
- Pen touch events are routed to the ink layer.

### 2. Independent ink model
- Adds `InkDocument`, `InkStroke`, and `InkPoint` models.
- Ink changes never mutate `LinkedListDocument`.
- Stroke history is separate from graph undo/redo.
- Adds undo, redo, and clear ink controls.

### 3. Shared graph coordinate space
- Pen points are converted from canvas viewport coordinates into graph coordinates using the current scale and translation.
- Ink is rendered inside the transformed graph workspace, so annotations move and zoom with nodes and pointer edges.
- Adds coordinate mapping and pinch-anchor helpers.

### 4. Finger canvas gestures
- One-finger node selection and drag remain available.
- Two-finger pan moves the graph workspace.
- Pinch zoom scales around the pinch center.
- The graph and ink layers share the same transform.

## Intentionally not included yet

- Pen Kit `HandwriteComponent` / handwriting suite toolbar.
- Pen radial menu and custom pen tools.
- Shape recognition and conversion from sketches to graph objects.
- Semantic anchoring of ink strokes to individual nodes.
- Palm-rejection guarantee or device-specific stylus hardware shortcuts.
- Pressure/tilt-dependent brush rendering beyond the initial pressure-normalized width.
- Persistent project storage.

The first Alpha uses native ArkUI pointer/touch source classification rather than embedding Pen Kit's handwriting canvas. This avoids imposing the handwriting suite's separate scrolling model on the graph workspace.

## Tests added

- Finger/Pen source classification.
- Immutable ink document creation and append.
- Independent stroke removal.
- Screen-to-graph coordinate conversion.
- Pinch-anchor transform math.

## Verification status

**Not yet verified:** ArkTS compilation, unit test execution on the target toolchain, HAP packaging, or MatePad Pro 13.2 hardware behavior.

GitHub static checks only verify source presence and expected integration hooks. They do not prove M-Pencil input reporting, palm rejection, gesture arbitration, or drawing latency.

## MatePad acceptance checklist

1. Build with DevEco Studio 26.0.0.865 / HarmonyOS SDK 26.0.0.105.
2. Use M-Pencil to draw over empty canvas and over a node; confirm the graph node does not move.
3. Tap and drag nodes with a finger; confirm node selection and movement still work.
4. Use two fingers to pan and pinch-zoom; confirm nodes, pointer edges, and ink remain aligned.
5. Draw two strokes, undo one, redo it, then clear all ink.
6. Perform graph undo/redo after ink operations; confirm the two histories never undo each other's changes.
7. Test palm contact while writing and report any accidental graph gestures.
8. Test portrait, landscape, and split-screen widths.
