# AlgoLab 1.0.0

**Release line:** 1.0  
**App versionName:** `1.0.0`  
**App versionCode:** `1000000`  
**Platform:** HarmonyOS Stage / ArkTS / ArkUI  
**Target:** HarmonyOS API 26; MatePad Pro 13.2

## Included

- Native single-linked-list workspace with node creation, editing, moving, `next` linking/disconnecting, and `head` selection.
- Reachability and structural warnings for cycles, unreachable nodes, and broken chains.
- Undo and redo for structure editing.
- Deterministic C++ source generation from the linked-list model.
- C++ syntax highlighting, line numbers, and line-linked Chinese teaching annotations.
- Toggle to show/hide Chinese annotations.
- Floating code panel with drag, resize, horizontal/vertical scrolling, and compact font controls.
- Default code font size 14vp; presets 11/14/17vp and continuous 10–22vp adjustment.

## Known limitations

- C++ preview is read-only; no native C++ compiler or execution engine is included.
- Interactive memory visualization and local document persistence are not implemented.
- Connecting pointers still uses the select-source / select-target interaction rather than direct port dragging.
- This release does not claim feature completeness beyond the listed single-linked-list workflow.

## Verification

The user previously confirmed a successful DevEco Studio build and app launch on MatePad Pro 13.2 (HarmonyOS 7.0.0), using DevEco Studio 26.0.0.865 and HarmonyOS SDK 26.0.0.105 (API 26).

The final 1.0.0 integration also includes later code alignment, annotation toggle, and compact font-toolbar changes. Those latest UI changes have not yet been rebuilt and re-verified on the MatePad. GitHub Actions checks repository scripts and source invariants only; it is not a substitute for ArkTS compilation or device acceptance.
